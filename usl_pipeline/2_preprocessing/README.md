# Stage 2: Preprocessing

Turns uploaded study areas and scenarios into feature matrices and labels, ready for prediction. `../README.md` lists the Cloud Functions and what starts each one.

## Running

To run the checks, from the repository root: `scripts/test-local/preprocessing.sh`.

`notebooks/test_cloud_functions.ipynb` calls the functions by hand. Run it with this folder on the path and `usl_lib` installed.
